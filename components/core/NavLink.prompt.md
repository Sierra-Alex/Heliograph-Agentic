# NavLink

Navigation link used in the top nav and inline nav rows. Garnett Medium 14px, +2% tracking, 24px tall, 70% opacity that resolves to 100% on hover or when `active`. Set `caret` for links that open a dropdown; the caret is the same 5x2.5 glyph the top nav uses. Use `onDark` inside dark sections.

Do not add an underline on hover — opacity is the only hover treatment in Heliograph.
