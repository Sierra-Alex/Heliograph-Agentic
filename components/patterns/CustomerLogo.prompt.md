# CustomerLogo

A single customer mark, sized by `height` — 27px is the height the logo band and quote carousel use. `color="dark"` and `"light"` flatten the mark to one tone for rows where mixed brand colours would be noisy.

Only Yelp ships with the system; the rest of the customer set lives in a shared Figma library that was not part of this file. Pass `src` with a real logo file for anyone else — never redraw a brand mark by hand.
