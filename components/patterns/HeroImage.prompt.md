# HeroImage

The panel that sits beside a small hero's text: an 8px-padded frame holding a 32px-radius well — the largest radius in the system, used only here. `type="image"` tints the well in the hue's 02 step as a bed for an illustration, `"gradient"` fills it with the product-card gradient, `"placeholder"` leaves it grey.

Drop an `<img>` in as children. The source uses illustrations here, never photography.
