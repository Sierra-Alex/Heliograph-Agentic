# LgResourceCallout

One resource given a full section: an 8px-padded image frame on one side and an H3 `CoreTypeLockup` — tag, headline, subhead, button — on the other, 80px apart on a 40/48 padded surface.

The frame's fill matches the page so only the 16px-radius image reads; that is the double-radius motif again. `imagePosition="right"` mirrors it. On the deep hues the lockup switches to its on-dark colours automatically.
