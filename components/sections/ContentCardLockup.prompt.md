# ContentCardLockup

The blog / resources grid: an optional header, then `ContentCard`s in 16px-gapped rows — three up, or four and five splitting into 2+2 and 3+2 so the last row never leaves a hole.

`buttonInHeadline` controls the header CTA: `"none"` when each card carries its own link, `"both"` when the section needs a secondary action too.
