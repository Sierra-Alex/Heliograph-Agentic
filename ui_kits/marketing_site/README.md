# Marketing site UI kit

A clickable recreation of the Mixpanel marketing site built entirely from Heliograph components. Nav links switch pages in place (Platform → home, Solutions → product, Resources, Pricing).

| File | Screen |
|---|---|
| `index.html` | Shell: sticky TopNav + page switcher + Footer |
| `Home.jsx` | LgHero (sliced gradient), logo carousel, product card lockup, two Z-layouts |
| `Product.jsx` | SmHero, section header, two ProductCards, dark Z-layout |
| `Resources.jsx` | SmHero, three-up SmResourceCard grid, wide ResourceCard |
| `Pricing.jsx` | SmHero, annual/monthly toggle, three plan cards, contact form |

Image wells are intentionally left as the design system's grey placeholders and gradient panels — the source repo ships no product screenshots.
